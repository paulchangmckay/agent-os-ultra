# Cheatsheet — The Elements of Style

## Decision Rules

| Situation | Do this | Because |
|---|---|---|
| Joining two independent clauses, no conjunction | Semicolon, not comma | Comma alone = comma splice (Rule 5) |
| Joining two independent clauses, with and/but/for/or/nor | Comma before the conjunction | Rule 4 |
| Second clause starts with an adverb (therefore, thus, accordingly) | Semicolon, never comma | Adverbs aren't conjunctions (Rule 4/5) |
| Clause is essential to identify its antecedent | No commas (restrictive) | Removing it changes the meaning |
| Clause adds supplementary info about an already-identified thing | Commas both sides (non-restrictive) | Removing it leaves a complete statement |
| Choosing active vs. passive | Active, unless the paragraph's real subject is the thing acted on | Active is more direct (Rule 10) |
| A word could be cut without losing meaning | Cut it | Rule 13: every word must tell |
| You want a word/phrase to land with force | Put it at the sentence's end | End = position of emphasis (Rule 18) |
| Choosing "like" vs. "as" | "Like" before nouns/pronouns only; "as" before phrases/clauses | Ch 5 |
| Choosing "fewer" vs. "less" | Fewer = number, less = quantity | Ch 5 |
| A sentence needs case/character/factor/feature/nature/system to make sense | Find the concrete noun/verb hiding underneath | These are filler nouns (Ch 5) |

## Comma Decision Tree

1. Are you joining two independent clauses?
   - No conjunction → semicolon (Rule 5)
   - With and/but/for/or/nor → comma before conjunction (Rule 4)
   - Second clause starts with adverb (however, therefore) → semicolon regardless
2. Is there a parenthetic/interrupting phrase?
   - Test: remove it — does the sentence still stand complete? → Yes = parenthetic, comma both sides (Rule 3)
   - → No = restrictive, no commas
3. Is it a series of 3+ items with one conjunction?
   - → Comma after every item except the last (Rule 2) — except firm names

## Thresholds & Defaults

- **4 punctuation rules** (3 comma + 1 semicolon) cover ~19 of every 20 sentences' internal punctuation needs (Ch 1).
- **One paragraph = one topic**, no exceptions stated except very brief compositions and dialogue (each speaker change = new paragraph) (Rule 8).
- **Split infinitives**: avoid — "in disfavor... among nearly all careful writers," despite centuries of precedent (Ch 5).
- **"Etc."**: only correct at the end of an already-complete list, or trailing immaterial quoted words — never after "such as" or "for example."

## Tells & Smells

- If a sentence needs "the fact that," "case," "character," "factor," "feature," "nature," or "system" to hold together → it's padded; find the real noun or verb.
- If you're tempted to write "one of the most..." to open a paragraph → you're announcing significance instead of demonstrating it; cut the formula and start with the actual point.
- If two consecutive sentences both start with "but" → contrast-on-contrast; reorder so only one "but" is needed.
- If a sentence's opening participial phrase doesn't logically describe the grammatical subject → dangling modifier, likely to read as unintentionally comic.
- If a paragraph has three or more same-shaped loose sentences (X, and Y. X, but Y. X, so Y.) in a row → monotonous; recast some as simple, semicolon, or periodic sentences (Rule 14).
- If "however" opens a sentence and means "nevertheless" → wrong position; move it after the first word or clause.

## Trade-off: Loose vs. Periodic Sentences

| | Loose sentence | Periodic sentence |
|---|---|---|
| Structure | Complete meaning reached before the end | Main point withheld until the end |
| Effect | Easy, conversational, can feel casual | Suspenseful, emphatic |
| Risk if overused | Monotonous, sing-song (Rule 14) | Overly formal, strained |
| Best use | Everyday narrative, informal passages | Moments needing real emphasis |
